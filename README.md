Project Overview

This project redesigns and enhances an undergraduate Computer Architecture course to help students understand the fundamental principles of computer architecture and how those principles have evolved to support modern architecture cloud computing, and data-intensive workloads.

Course: [CMP 431 Computer Architecture]

This course introduces students to the fundamental principles of computer architecture and organization, focusing on the structure, behavior, and performance of modern computer systems. Students explore how hardware components—including the CPU, memory systems, input/output subsystems, and control units—work together to execute programs. Topics include data representation, digital logic circuits, processor datapath and control, instruction execution, memory hierarchy, and I/O mechanisms. Emphasis is placed on understanding the hardware–software interface and how architectural design choices impact system performance and efficiency. Through readings, discussions, quizzes, and applied exercises, students develop a foundational understanding necessary for advanced study in computer systems, operating systems, and computer engineering.

The course connects traditional computer architecture concepts—including processors, instruction execution, memory hierarchy, storage, input/output, pipelining, parallel processing, and performance—with contemporary computing environments such as cloud infrastructure, artificial intelligence platforms, and specialized hardware accelerators.

Through FacultyHack@Gateways 2026, the course extends traditional classroom-based architecture concepts into authentic computing environments using Science Gateway resources and cloud-based cyber infrastructure, particularly Jetstream2. Students will investigate how computing resources are provisioned, how architectural components interact within cloud environments, and how architecture decisions influence the performance and scalability of AI workloads.

A central theme of the redesigned course is the connection between traditional on-premises computer architecture and modern cloud architecture. Students will examine how foundational concepts such as CPUs, memory, storage, networking, parallelism, and accelerators are represented and implemented in Infrastructure as a Service (IaaS), Platform as a Service (PaaS), and Software as a Service (SaaS) environments.

Industry Integration

A major component of the course is connecting academic concepts to real-world enterprise computing.

Students will examine architecture from the perspective of an enterprise technology environment and explore how computer architecture supports systems used in different industries.

Industry examples will demonstrate how architecture decisions influence enterprise applications, data platforms, analytics environments, cloud systems, and AI solutions.



Redesigned Student Learning Experience

The course will follow a progression from foundational architecture concepts to modern AI and cloud architectures.

1. Understand

Students learn foundational computer architecture concepts.

2. Connect

Students connect processor, memory, storage, and I/O concepts to real computing systems.

3. Explore

Students investigate how those components are represented in cloud computing environments.

4. Experiment

Students use Jetstream2 and other computing resources to execute workloads and observe computing behavior.

5. Analyze

Students analyze how architecture affects application performance, scalability, and resource utilization.

6. Apply

Students examine how AI workloads influence the evolution of processors, memory systems, parallel computing, and specialized accelerators.

7. Design

Students apply their knowledge to design or evaluate a computing architecture capable of supporting an AI workload.



Implementation Notes

Session 1: Foundations

Review traditional computer architecture concepts and identify opportunities to connect them to modern cloud and AI environments.

Session 2: Cloud Architecture

Introduce virtualization, cloud computing, IaaS, PaaS, SaaS, and the relationship between physical and virtual computing resources.

Session 3: Jetstream2 Exploration

Introduce Jetstream2 and provide students with hands-on experience provisioning and using cloud computing resources.

Session 4: AI Workloads

Examine how AI and machine-learning workloads place demands on processors, memory, storage, parallel computing, and specialized accelerators.

Session 5: Architecture Analysis

Students compare traditional and cloud architectures and analyze how architectural decisions affect performance and scalability.

FacultyHack is a hands-on program designed to empower educators across disciplines to integrate High-Performance Computing (HPC) and Artificial Intelligence (AI) tools directly into their curricula.


FacultyHack provides participants with technical mentorship, hands-on experience with advanced cyberinfrastructure, and an opportunity to transform what they learn into practical instructional materials that can be used with their students. The program emphasizes reducing barriers to HPC, AI, Science Gateways, and national research cyberinfrastructure while creating sustainable pathways for these technologies to reach new institutions, faculty, and students.
